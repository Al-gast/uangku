# UangKu

Mobile-first personal finance PWA foundation built with Next.js, TypeScript,
Tailwind CSS, and pnpm.

## Getting Started

Install dependencies and run the development server:

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).

## Foundation scope

- App Router routes for dashboard, cashflow, chat, portfolio, settings, login,
  and onboarding
- Mobile app shell and bottom navigation
- Centralized light/dark/system-ready CSS variables
- Emerald, Blue, Purple, Orange, and Mono accent tokens
- Static appearance preview

Auth, database integration, business logic, and PWA installability are
intentionally deferred.
